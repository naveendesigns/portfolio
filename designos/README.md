# DesignOS

DesignOS is an interactive concept prototype exploring AI-native product design infrastructure.

It connects design systems, research, product decisions, and engineering context into one intelligent layer so designers can make decisions with their team's existing knowledge instead of starting from scratch.

## Structure

- `index.html` - interactive DesignOS landing page and product prototype
- `css/styles.css` - visual system and responsive layout
- `js/app.js` - interactions, mock data, and prototype behavior
- `favicon.svg` - DesignOS favicon
- `robots.txt` - crawler instructions
- `sitemap.xml` - DesignOS sitemap

## Notes

This is a portfolio concept and front-end prototype. It uses vanilla HTML, CSS, and JavaScript with local mock data. No backend or production AI service is required to run the experience.
