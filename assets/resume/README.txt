This folder is for the resume PDF.

To enable the Resume links across the site:

1. Place the PDF here, named exactly:  Naveen-Kumar-Resume.pdf
2. Open data.js and change:

       resume: null

   to:

       resume: "assets/resume/Naveen-Kumar-Resume.pdf"

The Resume link then appears automatically in the desktop navigation,
the mobile menu and the contact section. No other file needs editing.

Expected file:  assets/resume/Naveen-Kumar-Resume.pdf
