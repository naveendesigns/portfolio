# More Retail case study assets

All seven supplied mobile screens are 412 px wide PNG exports. The original screen content is used unchanged inside a CSS phone frame. Each screen links to its full-size PNG in a new tab.

Three original transparent PNG doodles, `illustrations/store-manager.png`, `illustrations/store-associate.png` and `illustrations/network-doodle.png`, introduce the project roles and connectivity idea. They are separate illustrations created for this case study.

| File | Dimensions | Case study use |
| --- | ---: | --- |
| `screens/home.png` | 412 × 917 | Hero and home task callouts |
| `screens/receiving-delivery.png` | 412 × 1018 | Receiving progress and offline-saved state |
| `screens/edit-product.png` | 412 × 917 | Received, damaged and calculated quantities |
| `screens/report-issue.png` | 412 × 917 | Product issue reporting |
| `screens/receiving-complete.png` | 412 × 1018 | All products checked and attention state |
| `screens/receiving-review.png` | 412 × 1018 | Delivery review and totals |
| `screens/receiving-submitted.png` | 412 × 917 | Submission confirmation |

The procurement-to-audit map, duplicate-record proposal and Store Edge Network diagram are editable flow diagrams rendered from case study data in `data.js`. They are explanatory concepts based on the assignment brief, not More Retail infrastructure or verified company processes.
